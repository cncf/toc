# Project review templates

This directory contains reusable templates and guidance for CNCF project governance and technical reviews.

Governance and technical reviews are part of the TOC project lifecycle and due diligence process. The TOC retains responsibility for criteria interpretation, review delegation, and maturity decisions. TAG Chairs, Tech Leads, and delegated reviewers provide domain expertise and review capacity when requested by the TOC.
