# 1. Introduction and problem statement

Status: outline. Owner: Pavan Madduri (@pmady).

- Why distributed agentic systems need cloud native foundations: dynamic execution lifecycles (from sub-second tool calls to long-running loops), probabilistic control flow, dynamic tool calls, persistent memory, streaming transport
- Audience: platform teams, project maintainers, standards authors
- Relationship to the Cloud Native Agentic Standards: this document extends them for Kubernetes and does not restate them; it is maintained continuously, so it stays current as the standards and the ecosystem move
- Scope and non-goals: no new frameworks or runtimes; single-cluster baseline, multi-cluster first class
