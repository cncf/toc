# 1. Introduction and problem statement

Status: outline. Owner: Pavan Madduri (@pmady).

- Why distributed agentic systems need cloud native foundations: long-running probabilistic loops, dynamic tool calls, persistent memory, streaming transport
- Audience: platform teams, project maintainers, standards authors
- Relationship to the Cloud Native Agentic Standards: this document extends them for Kubernetes and does not restate them
- Scope and non-goals: no new frameworks or runtimes; single-cluster baseline, multi-cluster first class
